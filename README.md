# FrameNest

FrameNest is a plain HTML, CSS, and JavaScript image-search app that will let users search a topic and explore matching images in a responsive gallery. I chose a warm cream, teal, and coral palette to create a calm editorial feel instead of copying the reference's purple look. I used a split hero layout so the app explains its purpose before the search controls, while a quick-pick chip row gives users ready-made topics. A visible empty-state message and result-count placeholder also make the waiting state clear before Part 2 adds real image results.Part 1 UI scaffold completed with a responsive search layout and empty results grid.
